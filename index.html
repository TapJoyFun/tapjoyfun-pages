TapJoyFun Uploader

TapJoyFun Uploader is a small personal tool that uploads gameplay videos to the TapJoyFun YouTube channel. It runs on the channel owner's own computer and uses the YouTube Data API to upload videos, set thumbnails, add videos to playlists, and schedule publish times.

It is used only by the channel owner, for the owner's own videos. It does not collect, store, or share data from anyone else.
